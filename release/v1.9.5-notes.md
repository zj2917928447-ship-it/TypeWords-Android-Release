# TypeWords Android v1.9.5 — 键位分析与薄弱项专项训练

## 版本信息

- Android package：`cc.typewords.android`
- versionName：`1.9.5`
- versionCode：`25`
- Minimum Android：6.0 / API 23
- 基线：v1.9.4
- 继续保留 Nuxt + Vue、Android WebView、IndexedDB、FSRS-6 和现有 ZIP 学习数据备份格式。

## 本版修订

### 1. 真实击键统计

- 单词打字练习中按目标键统计命中与错误；错误归因到“本应按下的键”，而不是把错按的键误判为薄弱键。
- 记录退格修正次数。
- 只在两个相邻目标字母都正确输入时采集 bigram 转换耗时；间隔超过 3 秒不计入转换样本，避免长时间停顿污染速度数据。
- 空格、标点、非英文字母和点按自测不进入键位热力图。
- 只保存按键聚合计数和转换耗时，不保存逐键原始时间序列；不接入独立分析/遥测服务。统计作为现有 reviewEvents 的可选字段保存，若用户启用了应用原有云同步，会随学习数据一起同步。
- 结果页按最近 30 天汇总；键位至少 3 次有效样本、组合至少 3 次转换样本才进入弱项排序。为控制数据体积，键位明细保留最近 90 天、最多 5,000 条；清理只删除可选 typing 明细，不删除 FSRS 复习事件。

### 2. 键位热力图与弱项训练

- 在练习结算统计中增加 QWERTY 字母键热力图、薄弱键位、较慢字母组合。
- 训练候选只从当前词书中已学习且尚未被忽略/掌握的词汇选择，最多 20 个。
- 点击“按薄弱项开始专项训练”后复用现有练习流；手机端自动切换为键盘输入模式，避免进入无法训练键位的点按流程。
- 没有足够样本时显示明确提示，不虚构准确率或弱项。

### 3. 数据兼容与 FSRS 边界

- 练习过程中的临时统计放在现有练习缓存可选字段 `typingTelemetryMap`。
- 单词结算时把小型可选聚合 `typing` 附加到现有 `reviewEvents`；旧事件不要求迁移，旧 ZIP 备份仍可导入。
- 继续使用 ts-fsrs 5.4.2 / FSRS-6，不改 21 个权重、历史卡片、到期时间和评分。
- 击键错误统计与 FSRS 记忆评分分离；打错一个字母不会被改写为额外的 Again 评分。
- 修复整词输入模式下完整拼错但没有调用错误结算回调的问题，避免错词统计漏记。
- 忽略字符键的自动重复 keydown，避免长按按键虚增击键次数；退格仍保留原有重复行为。

## GitHub 研究

第三轮候选与许可审查记录见 `docs/github-research-20261115.md`。

本版仅采纳公开项目的产品思路并独立实现，不复制外部源代码、字体、图标或训练语料：

- TYPE / type.review（MIT）：热循环与 UI 解耦、按键/手指统计、键盘热力图和自适应练习设计参考。

- typrlab：专有许可证，仅作功能观察，不复制代码、文案、素材或衍生实现。
