# TypeWords Android v1.9.6

## Android 软键盘输入与兼容性修复

- 包名：`cc.typewords.android`
- 版本：`1.9.6`
- versionCode：`26`
- 最低 Android：6.0 / API 23
- 基线：v1.9.5

### 主要更新

1. 统一处理 Android / 浏览器 `InputEvent`：单字符 `insertText`、`deleteContentBackward`、`insertLineBreak` 和 `insertParagraph`。
2. 兼容 Android IME 只发送 InputEvent、keydown 为 `Unidentified / keyCode 229` 的输入路径。
3. 修复 keydown/input 双事件去重后隐藏输入框哨兵未复位的问题。
4. 拒绝多字符粘贴、整词自动纠错和中文 IME 合成提交，避免污染键位错误统计。
5. 将 API 27 的导航栏主题属性移至 `values-v27`，保护 Android 6.0–8.0 的基础主题兼容性。

### 学习数据与 FSRS

- 保留 Nuxt + Vue、Android WebView、IndexedDB、原词库和 ZIP 学习数据备份格式。
- 继续使用 ts-fsrs 5.4.2 / FSRS-6。
- 不改变 21 个 FSRS 权重、历史卡片、复习评分和到期时间。
- 不新增独立遥测服务或逐键原始输入日志；保留 v1.9.5 的可选键位聚合统计。
