## Changes

1. Enables Android 15/16 edge-to-edge with transparent status/navigation bars.
2. Applies safe insets for system bars, display cutouts and the on-screen keyboard to the WebView viewport.
3. Removes the portrait-only lock, supports rotation and reapplies insets after configuration changes.
4. Keeps Vue's app-back handling connected to Android predictive back on API 33+.
5. Adds Android 13+ themed monochrome launcher masks for standard and round adaptive icons.
6. Clamps NaN/Infinity TTS speech-rate and volume inputs to safe defaults.
7. Handles the modern TTS error callback and stops active speech when the app leaves the foreground.
8. Keeps the existing FSRS-6 scheduler, wordbooks, offline dictionary, IPA overlay and ZIP backup format.
