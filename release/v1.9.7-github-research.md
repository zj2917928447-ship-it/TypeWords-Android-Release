## v1.9.7 engineering decisions

- Keep the existing TypeWords Vue/Nuxt + Android WebView architecture; do not replace it with Flutter/Kotlin merely because a candidate uses a native stack.
- Keep FSRS-6 / ts-fsrs 5.4.2; do not replace it with a simpler interval schedule or migrate cards to FSRS-7 without a migration/parity test.
- Keep learning data local and retain the existing ZIP backup schema.
- Use AnkiDroid as a reference for native TTS lifecycle, not as code to transplant.
- Use type.review and Qwerty Learner as references for typing analytics, not as data or code sources.
- Use Lexio/Kotoba as design references for typed recall and import/backup UX.
- Keep WordTap media, recordings and text out of the APK unless each asset has a clear, compatible license.

## Release verification boundary

The v1.9.7 APK was built locally for Android API 36, signed, aligned and linted. The Android device acceptance test is still pending because ADB reported no authorized phone. The public v1.9.7 release is not published yet; it must be uploaded and verified from the live local HTTPS download server.
